# R16 · RCM-3 → RCM-3F：固定信号，放大预算

2026-06-24 · 风险表达 · 保留 · 风险预算比较

**研究问题**

在不改变交易决策的情况下，提高风险预算如何影响收益与回撤？

**检验方法**

继承规则仅将杠杆乘 1.50；分别匹配开发期 365 笔和历史期 510 笔。

**观察结果**

开发收益 169.20% → 317.66%，回撤 13.29% → 19.38%；历史收益 193.81% → 358.45%，回撤 20.95% → 30.09%。

**研究裁决**

保留 3F 作为较高风险预算版本。

**留下的认识**

交易、退出和胜率不变。收益提升的直接机制是风险放大，3F 与 3 共用同一个信号来源。
